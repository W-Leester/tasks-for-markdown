# 포스트모템: VS Code Marketplace 첫 업로드 거절 ("suspicious content")

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-01 (KST) |
| 대상 | Tasks for Markdown 1.0.0 (`HastyCapybara.tasks-for-markdown`) 첫 공개 |
| 영향 | 공개가 하루 이상 늦어짐. 사용자 영향 없음(아직 공개 전) |
| 상태 | 원인 좁힘 완료, 검색어 교체(a20c931). **12시간 생성 한도 해제 후 재업로드 대기** |
| 관련 | [Tasks.md M20](../Tasks.md), [배포 가이드라인 5.3](../publishing-guide.md#53-marketplace가-거절할-때) |

이 문서는 누구의 잘못을 따지려는 것이 아니라, 같은 일이 다시 생겼을 때 더 빨리 끝내기 위한 기록이다.

---

## 1. 요약

VS Code Marketplace 웹 업로드가 **"Your extension has suspicious content. Please fix your extension metadata, or contact support"**로 거절됐다. Marketplace는 어느 항목이 문제인지 알려 주지 않는다.

처음에는 코드(외부 프로그램 실행, 자체 업데이트)를 의심해 기능을 지웠지만 **같은 오류가 났고 되돌렸다**. 이후 시험 확장 16개를 올려 반씩 나누는 방식으로 좁혔다. 원인은 **`package.json`의 검색어(keywords)**였다. `checklist`, `kanban`, `calendar`, `gtd`가 들어가면 거절됐다. 검색어를 통과가 확인된 것으로 바꿨다. 다만 시험 업로드가 너무 많아 **"12시간 동안 만들 수 있는 확장 수 초과"** 제한에 걸려 재업로드를 기다리는 중이다.

## 4. 원인

**직접 원인:** `package.json` `keywords`의 `checklist`, `kanban`, `calendar`, `gtd`.

**확실하지 않은 점:** 네 단어를 하나씩 넣은 마지막 네 개가 모두 거절된 것은 두 가지로 설명할 수 있다.
1. 다른 확장의 이름과 같은 일반 명사를 검색어로 넣는 것을 "검색어 끼워 넣기"로 보는 규칙. `Kanban`, `Calendar`, `Checklist`, `GTD`라는 이름의 확장이 실제로 있다.
2. 짧은 시간에 비슷한 확장을 계속 만들면서, 생성 한도에 가까워져 판정이 엄격해진 경우.

어느 쪽이든 **해당 단어를 빼면 된다**는 결론은 같다. 재업로드 결과로 확정한다.

**관련 없었던 것(오해했던 것):** 외부 프로그램 실행 코드, 자체 업데이트 코드, "Obsidian"·"VS Code"·"Cursor" 같은 다른 제품 이름(소개문·README), 배너, 문서 내용.

## 5. 잘한 점
- 기능 제거를 **바로 되돌렸다**(기록을 지우지 않는 `git revert`). 쓸모없는 기능 손실이 남지 않았다.
- 시험을 **반씩 나누는 설계**로 했다. 매 회차마다 결과 표로 판단 기준을 먼저 정해 두어 결과 해석이 빨랐다.
- 시험 확장마다 이름과 설명에 "Upload test, will be removed"를 넣어, 잠깐 공개돼도 혼란이 없게 했다.
- 진행 중 생긴 CI 실패 메일을 원인 분석(로그 확인)으로 별개 문제라고 판단했고, 재발 방지(재시도)까지 했다.
- 태그(Open VSX·npm 게시)를 Marketplace 통과 전에 올리지 않았다. 같은 버전 번호를 다시 쓸 수 없기 때문에 이 순서가 버전 불일치를 막았다.

## 6. 아쉬운 점
- **첫 가설을 시험 없이 코드 수정으로 옮겼다.** 오류 문구가 "metadata"라고 했는데도 코드부터 의심했다. → 처음부터 "코드 같고 정보 최소" vs "정보 같고 코드 최소" 두 시험으로 갈랐으면 한 번에 방향이 잡혔다.
- **시험을 너무 많이·빠르게 올려** 12시간 생성 한도에 걸렸다. 마지막 회차(⑬~⑯)의 결과도 그 영향을 받았을 수 있다.
- 검색어를 정할 때 "많을수록 좋다"고 보고 일반 명사를 넣었다. 마켓 검사 규칙을 몰랐다.
