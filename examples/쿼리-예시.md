# 쿼리 예시

각 블록 위의 CodeLens `▶ 결과 보기`를 누르면(또는 커서를 블록 안에 두고 `Tasks: 커서 위치 쿼리 결과 보기`) 에디터 옆 패널에 결과 목록이 열리고, 커서를 다른 블록으로 옮기면 따라옵니다. VS Code 마크다운 미리보기(`Cmd+K V`, Markdown: Open Preview to the Side)에서는 블록 자리에 결과가 렌더링됩니다. Cursor의 "Preview" 토글은 자체 편집기라 블록이 코드로만 보이고 `Cmd+Shift+V`도 그 토글에 묶여 있으니, "Markdown" 모드에서 CodeLens나 `Cmd+K V`를 쓰세요. `? 설명`은 해석 결과와 일치 수를 보여줍니다. 결과는 워크스페이스 전체 태스크 대상입니다.

## 1. 기본

미완료 전체, 긴급도 순:

```tasks
not done
sort by urgency
```

이 파일이 있는 폴더의 태스크만:

```tasks
not done
folder includes {{query.file.folder}}
```

## 2. 날짜

기한 초과:

```tasks
not done
due before today
sort by due
```

이번 주 안에 해야 할 일 (마감·예정·시작 중 가장 이른 날짜 기준):

```tasks
not done
happens before next week
sort by happens
group by happens
```

다음 주 마감:

```tasks
not done
due next week
```

10월 마감:

```tasks
due 2026-10
```

마감일이 없는 미완료:

```tasks
not done
no due date
```

최근 7일 안에 완료한 것:

```tasks
done after 7 days ago
sort by done reverse
```

## 3. 우선순위·태그·텍스트

높은 우선순위 이상:

```tasks
not done
priority is above medium
sort by priority
```

#업무 태그 중 #프로젝트A는 제외:

```tasks
not done
tags include #업무
tags do not include #프로젝트A
```

설명에 "보고서"가 들어간 것:

```tasks
description includes 보고서
```

정규식 — "사기" 또는 "예약"으로 끝나는 것:

```tasks
description regex matches /(사기|예약)$/
```

## 4. 불리언 조합

기한 초과이거나 최고 우선순위:

```tasks
not done
(due before today) OR (priority is highest)
```

업무이면서 이번 주가 아닌 것:

```tasks
(tags include #업무) AND NOT (happens before next week)
not done
```

중첩:

```tasks
((tags include #건강) OR (tags include #집안일)) AND (has due date)
```

## 5. 반복·의존성·구조

반복 태스크만:

```tasks
is recurring
group by recurrence
```

다른 태스크에 막혀 있는 것 / 다른 태스크를 막고 있는 것:

```tasks
not done
(is blocked) OR (is blocking)
group by function task.isBlocked ? "차단됨" : "다른 태스크를 막는 중"
```

(위 블록의 `group by function`은 설정 `tasksmd.query.allowFunctions`를 켜야 동작합니다. 끄면 오류가 표시됩니다.)

하위 항목 제외:

```tasks
not done
exclude sub-items
```

## 6. 그룹·정렬·레이아웃

파일 → 헤딩 두 단계 그룹:

```tasks
not done
group by filename
group by heading
```

마감일별로 그룹, 각 그룹 최대 3개 그룹만:

```tasks
not done
has due date
group by due
limit groups 3
```

짧은 표시 + 일부 숨김:

```tasks
not done
short mode
hide backlink
hide task count
limit 5
```

설명 보기 (`explain`을 넣으면 블록 위에 해석이 표시됩니다):

```tasks
not done
due before next monday
priority is not none
explain
```

## 7. 잘못된 날짜·오류 확인

```tasks
due date is invalid
```

의도적으로 틀린 명령 (오류 표시 확인용):

```tasks
not done
sort by banana
```
