# Use your tasks from the terminal

**Tasks: Install 'tasksmd' command in PATH** adds a `tasksmd` command:

```bash
tasksmd query "not done
due before tomorrow"
tasksmd add "- [ ] Call the bank 📅 2026-10-12" --file notes/inbox.md
tasksmd done notes/work.md:12
```

It runs on the editor's own Node and keeps working after updates. Remove it with **Tasks: Uninstall 'tasksmd' command**.
