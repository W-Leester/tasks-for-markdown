# Create a task

A task is a checklist line in any Markdown file:

```markdown
- [ ] Write the report #work ⏫ 📅 2026-09-25
- [ ] Water the plants 🔁 every 3 days 📅 2026-10-03
```

- `Option+Shift+C` (macOS) / `Alt+Shift+C` (Windows, Linux) opens the create/edit dialog.
- `Cmd+Shift+C` (macOS) / `Ctrl+Shift+C` (Windows, Linux) turns the current line into a checkbox (`- [ ]`) — press it again to take the box off.
- `Option/Alt+C` on a task line marks it done; a recurring task gets its next occurrence.
- Type `due`, `priority high` or `every week` on a task line for suggestions; dates can be words like `next fri`.
